unlocker

利用unlocker工具 解锁VMWare中的Apple选项

首先关闭VMWare，尽可能的停用VMWare的相关的后台服务

以下unlocker有两种运行模式，选择一种即可。

1、https://github.com/paolo-projects/unlocker

下载完成后，解压缩，找到win-install.cmd，以管理员身份运行即可。

2、https://github.com/DrDonk/unlocker

下载完成后，解压缩，找到unlocker.exe，双击运行即可

获取macOS的官方恢复环境

下载

进入以下仓库，在右侧点击进入[1]链接

[0] https://github.com/dortania/OpenCore-Install-Guide

在以下链接选择Making the installer in Windows栏目，然后点击macrecovery.py，进入[2]链接仓库；在[1]号链接点击This will require Python 3 installed，进入[3]号链接

[1] https://dortania.github.io/OpenCore-Install-Guide/installer-guide/windows-install.html

点击OpenCore-0.8.8-RELEASE.zip下载最新的release版本压缩包即可下载

[2] https://github.com/acidanthera/OpenCorePkg/releases

以下链接选择Download Windows embeddable package (640bit)，下载Python下载

[3] https://www.python.org/downloads/windows/

进入QEMU官方 https://qemu.org ，选择DOWNLOAD，选择Windows栏目，点击64-bit，下载QEMU下载

将下载好的三个文件全部解压缩，QEMU是exe文件，也当成压缩文件进行解压缩即可。只是这里使用7z解压会有个报错，建议使用Bandizip进行解压

步骤

打开解压好的Python文件夹，空白处Shift + 右击 选择 Powershell 窗口

执行命令.\python.exe [0] [1]

注：[0] opencore文件夹下的路径 D:\Downloads\OpenCore-0.8.8-RELEASE\Utilities\macrecovery\macrecovery.py

[1] https://dortania.github.io/OpenCore-Install-Guide/installer-guide/windows-install.html#downloading-macos 这个网站复制

# Latest version
# ie. Ventura (13)
python3 macrecovery.py -b Mac-4B682C642B45593E -m 00000000000000000 download

实际执行 指令

.\python.exe D:\Downloads\OpenCore-0.8.8-RELEASE\Utilities\macrecovery\macrecovery.py -b Mac-4B682C642B45593E -m 00000000000000000 download

等待下载完成，会在Python文件夹生成com.apple.recovery.boot文件夹，在com.apple.recovery.boot文件夹下有一个BaseSystem.dmg文件，将此文件复制到，QEMU文件夹下。

然后在QEMU文件夹下，空白处Shift + 右击 选择 Powershell 窗口，执行命令

.\qemu-img.exe convert -O vmdk -o compat6 BaseSystem.dmg BaseSystem.vmdk

等待执行完成后，会生成一个BaseSystem.vmdk虚拟磁盘文件

创建虚拟机

打开VMWare 点击 新建虚拟机

选择 自定义 点击 下一步

默认 17.x 点击 下一步

选择 稍后安装操作系统 点击 下一步

选择 Apple Mac OS X(M) - macOS 13 点击 下一步

虚拟机名称随意，位置为安装的虚拟机的位置，选择一个合适的位置即可 点击 下一步

处理器数量 1；每个处理器的内核数量 8 点击 下一步

内存 分配8G 点击 下一步

网路类型 默认 点击 下一步

选择I/O控制器类型 默认 点击 下一步

选择磁盘类型 默认 点击 下一步

选择磁盘 默认 点击 下一步

指定磁盘容量 100G；将虚拟磁盘存储为单个文件 点击 下一步

指定磁盘文件 默认 点击 下一步 接着 点击 完成

关闭VMWare

找到虚拟机安装到的磁盘位置，找到macOS 13.vmx文件，使用文本编辑器打开，搜索e1000e，将e1000e替换成为vmxnet3，保存关闭。

打开VMWare，选择macOS 13 点击 编辑虚拟机设置，如果没有CD/DVD驱动器，将此选项中的 启动时连接 取消勾选。

然后在下方点击添加按钮 选择 磁盘-下一步 SATA(A)-下一步 选择 使用现有虚拟磁盘-下一步 浏览QEMU文件夹下生成的BaseSystem.vmdk虚拟磁盘文件，点击完成 点击 保持现有格式 确定即可。

然后开启虚拟机，先在磁盘工具中将VMware Virtual SATA Hard Drive Media抹掉，然后名称为macOS或其他自定义名称都可，格式默认APFS，方案默认GUID分区图，点击抹掉。

然后选择重新安装macOS Ventura，选择上一步抹掉的磁盘一直按提示操作即可。

然后macOS会自动恢复下载官方系统并安装，耐心等待安装完成即可。

进入桌面点击虚拟菜单中的重新安装VMware Tools，在macOS中安装VMware Tools即可恢复正常分辨率。

电脑

所需文件云盘地址：https://cloud.189.cn/t/iuYVZbQnuQ7b (访问码:qo2y)

准备

首先要准备好以下文件、软件、硬件：

  • macOS Catalina 10.15.7 19H2.dmg

  • XiaoMi_Pro-KBL-Clover-v1.7.4.zip

  • DG521941_x64.zip

  • balenaEtcher-Setup-1.13.1.exe

  • 一个8G以上的U盘

以上最重要的就是EFI文件，EFI文件每台机器都不同，不可通用，需要自己寻找

刻录U盘

安装并打开balenaEtcher软件，选择macOS Catalina 10.15.7 19H2.dmg进行刻录

EFI

利用DiskGenius软件将EFI文件替换掉电脑硬盘中的EFI文件，不是替换U盘中的EFI文件。

如果硬盘没有EFI分区，请使用DG软件进行设置即可

安装

U盘插入电脑，使用U盘进行启动即可
